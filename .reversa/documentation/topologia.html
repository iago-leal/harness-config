Topologia de Arquivos

Evolução da distribuição física e footprint de arquivos do projeto.

Paradigma: Autocontido
Status: Migrado

Topologia Legada (Antes da f005) Footprint disperso

Configurações e estados ficavam dispersos na raiz do projeto e em pastas duplicadas, complicando o versionamento e isolamento do harness.

project_root/
├── claude-config/            # Purgado (commit 5624f78)
│   ├── settings.json
│   └── skills.active
├── decisoes/               # Movido para .harness/
│   ├── MD-0001.md
│   └── MD-0002.md
├── ESTADO-DA-SESSAO.md      # Movido para .harness/
├── harness-core/            # Módulo CLI e MCP
│   └── src/
└── harness                  # Wrapper script bash

• Acoplamento com caminhos literais fixos na raiz.

• Risco de conflito com arquivos de outros plugins da IDE.

Topologia Moderna (Atual) Autocontida / Limpa

Evolução consolidada pela Feature 005 e ADR 0009. Todo o estado mutável do harness reside dentro da pasta oculta .harness/.

project_root/
├── .harness/                  # Novo diretório centralizado
│   ├── estado-da-sessao.md     # Estado de sessão unificado (f004)
│   ├── microdecisoes.md       # Índice compilado de decisões
│   └── decisoes/             # Pasta de microdecisões (f005)
│       ├── MD-0001.md
│       └── MD-0002.md
├── harness-core/            # CLI Python e MCP
│   ├── src/
│   └── harness.toml            # Configuração tipada (f005/f006)
└── harness                  # Wrapper script bash

• Centralização: Caminhos de decisões resolvidos dinamicamente de harness.toml.

• Footprint Zero: Sem escritas fora da pasta do projeto (respeitando BR-MIGRAR-007).

Decisões Arquiteturais Relevantes (ADRs)

ADR Decisão Impacto na Topologia
ADR 0009 Abandono completo do diretório legado claude-config/. Sumiço de arquivos duplicados da raiz e centralização de segregação na pasta .harness/.
ADR 0010 Criação do estado de sessão unificado e idempotente. Substituição de arquivos temporários e múltiplos na raiz pelo arquivo .harness/estado-da-sessao.md.
ADR 0012 Carregamento de caminhos de decisões via configuração dinâmica. Substituição de caminhos absolutos hardcoded por rotas lidas do harness.toml.
