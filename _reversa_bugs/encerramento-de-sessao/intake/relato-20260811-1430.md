2. **Erro de shell durante o fluxo (sintoma).** A saída colada pelo usuário é de um comando zsh
   improvisado pelo agente daquela sessão (padrão `ls` + `cat _cabecalho.md MD-*.md`): no momento da
   execução não havia ficha `MD-*.md`, e glob sem correspondência é erro fatal no zsh
   (`no matches found`), com `cat: :` de argumento vazio na sequência. Anotado como evidência do
   problema 1, não como bug próprio: o improviso só existiu porque o índice era inútil como fonte.

   `.harness/estado-da-sessao.md` daquele projeto registra: "Estado de sessão corrigido: o
   `start_time` nulo abortava o `encerrar-sessao`; ganhou o instante do commit-âncora". Ou seja, o
   agente da sessão editou o front-matter manualmente para destravar o fechamento. Anotado como
   contexto; sem defeito autônomo comprovado no core até segunda ordem.
