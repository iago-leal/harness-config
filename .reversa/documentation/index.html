Projeto Harness

CLI Python e servidor MCP em arquitetura hexagonal para harness de agentes, suportando formatação automática, controle de sessões, indexação de microdecisões e ganchos Git.

🚀 Guia Rápido de Instalação (For Dummies)

1. Vá para a pasta do projeto

Abra o Terminal e entre no diretório do projeto:

cd ~/dev/harness

2. Crie e ative o ambiente virtual (venv)

Isto isola as dependências do Python para não quebrar seu sistema:

cd harness-core
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cd ..

3. Dê permissão ao atalho local

Permite que você execute o comando simplificado no terminal:

chmod +x harness

4. Teste a integridade das microdecisões

Rode o comando de teste para validar o grafo:

./harness decisions

5. Inicie o servidor de documentação local

Dispara o servidor local na porta 8000:

./harness doc-serve

Acesse http://localhost:8000 no seu navegador para ver a documentação.
