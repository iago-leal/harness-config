Como rodar o Harness

Passo a passo amigável, do zero até a documentação no navegador.

👋 Nunca rodou o Harness? Comece por aqui.

Cinco passos, do zero até ver esta documentação no navegador. Copie cada bloco cinza, cole no Terminal e aperte Enter. Sem pressa — cada passo explica o que faz e o que você deve ver.

🧰

Antes de começar: o que você precisa ter

Só duas coisas, que provavelmente já estão no seu Mac. Para conferir, cole os comandos abaixo no Terminal — se aparecer um número de versão em cada um, está tudo certo.

  • Python 3 — confira com python3 --version
  • Git — confira com git --version
1

Abra o Terminal na pasta do projeto

Todos os comandos seguintes rodam de dentro desta pasta. Este comando leva o Terminal até lá. 

cd ~/dev/harness

✅ O texto antes do cursor deve terminar com harness.

2

Prepare o ambiente só na 1ª vez

Isto cria uma “caixinha” isolada de Python (a pasta .venv) e instala as bibliotecas que o Harness usa. Você só faz isto uma vez. 

cd harness-core
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cd ..

✅ Ao final, o cursor volta para a pasta harness e não há mensagens de erro vermelhas.

3

Libere o atalho ./harness só na 1ª vez

Dá permissão para o atalho ./harness ser executado. Sem isto, o Terminal recusa rodá-lo. 

chmod +x harness

✅ Nenhuma mensagem aparece — silêncio aqui é sinal de sucesso.

4

Teste se está tudo funcionando

Este comando valida as microdecisões do projeto. É o jeito mais rápido de confirmar que a instalação deu certo. 

./harness decisions
O que você deve ver
Grafo de microdecisões validado com sucesso (zero erros).
Índice de decisões compilado com sucesso em '.harness/microdecisoes.md'.

✅ Apareceu isso? Pronto, o Harness está rodando.

5

Veja esta documentação no navegador

Sobe um pequeno servidor local e abre esta mesma página no seu navegador, sempre atualizada. 

./harness doc-serve

Agora acesse http://localhost:8000. Para parar o servidor quando terminar, aperte Ctrl + C no Terminal.

✅ A página abriu? Esse é o fim do passo a passo.

🤖

Bônus: conectar ao seu agente de IA

Para o Harness agir sozinho dentro do Claude ou Gemini (formatar código, retomar sessões), gere o prompt de instalação e cole-o no agente — ele cuida do resto: 

./harness install-prompt

Para instalar também os ganchos de Git locais (pre-commit e post-merge), rode ./harness bootstrap.

🛟

Deu erro? Respira, é rápido de resolver

  • “ambiente virtual não está configurado” — você pulou o Passo 2. Volte e rode-o por inteiro.
  • command not found: ./harness — confira o Passo 1 (pasta certa) e o Passo 3 (o chmod +x).
  • python3: command not found — instale o Python 3 (veja os pré-requisitos no topo).
